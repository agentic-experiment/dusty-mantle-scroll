# Dusty Mantle Scroll

A vertical descent through the Earth's geological layers — from thin soil to solid iron core — rendered as a meditative scroll experience with floating dust particles and gradual text reveals.

## Reasoning

1. **Name interpretation.** "Dusty-mantle-scroll" suggested three things: dust (particles, age, atmosphere), mantle (geology, layers beneath), and scroll (a document to unroll, or the act of moving down a page). I built around all three.

2. **Concept choice.** A layered descent through the Earth's structure — surface, crust, mantle, outer core, inner core, void. Each layer has its own color palette, texture, and tone. The writing is deliberately sparse and strange, treating geology as autobiography.

3. **Visual approach.** No frameworks, no build step. One HTML file with embedded CSS and JS. The design relies on CSS gradients for layered backgrounds, a fixed canvas for floating dust particles, and IntersectionObserver for scroll-triggered text reveals. A fixed depth indicator on the right edge acts as both navigation and progress.

4. **Color progression.** The palette shifts from warm browns and tans (surface) through sienna and burnt orange (mantle) to deep gold (core), darkening to near-black at the terminal void. Each transition is a CSS gradient on the section.

5. **Dust system.** A canvas overlay renders 80 particles that drift slowly, wobble with sine waves, and vary in opacity over time. They respond to scroll position with parallax, tying the floating debris to the act of descending.

6. **Scroll interactions.** `IntersectionObserver` with a 0.2 threshold fades in headings, paragraphs, and stratum lines as they enter the viewport. The depth nav highlights the current layer. All transitions use cubic-bezier easing for a slow, weighted feel.

7. **Simplifications.** No build tools, no dependencies, no analytics, no images. The entire experience is a single file under 200 lines of meaningful code. The dust is a simple particle loop, not a physics simulation. The depth nav is CSS-only with a JS scroll listener, not a library.
